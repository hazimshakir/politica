# Changelog

All notable changes to POLITICA are documented here. This project currently uses an informal changelog; releases and version tags will be added when a stable release is prepared.

## Unreleased

- Expanded the provisional thinker and book recommendation catalogue.
- Added source references and clickable citations where a source URL is available.
- Added result interpretation, tendency descriptions and export improvements.
- Improved assessment data validation and matching tests.
- Repository onboarding, contribution and CI documentation are being established.

## Release policy

A dated version entry will be created when a tagged release is published. Until then, the live demo may contain changes that are not part of a stable release.
