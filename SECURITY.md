# Security policy

## Supported deployment

The latest version on the `main` branch is the only version currently considered for security fixes. POLITICA is an experimental static website and does not currently operate an application backend or user account system.

## Reporting a vulnerability

Please do not publish exploitable details, personal assessment answers, credentials or tokens in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, contact the repository owner through the contact details on their GitHub profile and include only the minimum information needed to describe the issue.

Please allow reasonable time for investigation and a fix before public disclosure. Do not test against other people's accounts, devices or data.

## Data considerations

Assessment progress is stored in browser localStorage. Treat browser exports and screenshots as potentially sensitive because they may reveal political opinions.
